# Claude 風デザインへの統一（Coder 作業記録・レビュー用）

## 方針
- 暗い ChatGPT 風の配色をやめ、Claude アプリ風の暖色ライト配色に切り替えた。
  - 地は暖かいオフホワイトで、カードと入力欄は白にした。
  - 文字は落ち着いた濃い茶系にした。
  - アクセントは控えめなテラコッタ `#b95a3a` にした（レビューで `#c96442` から調整。白文字とのコントラストを 3.90 から 4.58 に上げた）。
- `src/theme.ts` のトークン名は維持し、値だけを差し替えた。全画面がテーマを参照しているため、画面ごとの書き換えは最小限で済んでいる。
- 新規トークンは `accent` / `accentPressed` / `onAccent` / `scrim` / `shadow` の 5 つ。
- 依存は追加していない。機能、画面遷移、データ処理、アクセシビリティラベルも変更していない。
  - 唯一の挙動変更は、下記「目標ループ」チップの表示条件。

## 変更ファイル
| ファイル | 内容 |
|---|---|
| src/theme.ts | 暖色ライトの配色にした。radius は 8/12/16 とやや丸めにした |
| src/components/ui.tsx | 主ボタンをテラコッタ塗りと白文字にした。補助ボタンは白地と枠線。入力欄はフォーカス時にアクセント枠を出す。SegmentedControl は白い選択面と淡い影。Chip の選択時はアクセントの淡色。Toggle のつまみは白。線は淡色化した。影とスクリムはトークン化し、エラーアイコンの直書き色も除去した |
| App.tsx | StatusBar を dark に変更した。承認の帯はサイドバー色の地で、リンクをアクセント色にした |
| src/screens/CloudAgentsScreen.tsx | 入力欄は白い箱に淡い影を付けた。送信ボタンはテラコッタ。空画面の見出しは端末標準のセリフ体にし、✻ をアクセント色にした。差分切替の選択時もアクセント塗り。目標ループのチップは既定値以外のときだけ出す |
| src/screens/RemoteScreen.tsx | 送信と停止の丸ボタンをアクセント塗りに白アイコンにした |
| src/screens/LoginScreen.tsx | ログインボタンをアクセント塗りに白文字にした |
| src/components/DecisionInbox.tsx | 主ボタンをアクセント塗りに白文字にした。件数バッジの文字は白 |
| src/components/TermsSheet.tsx | チェック済みのボックスをアクセント塗りにした |
| app.json | userInterfaceStyle を light に、スプラッシュの地色を `#faf9f5` に変更した |

以前は「濃い文字色を塗りに使い、その上に `colors.bg` の文字を置く」組み合わせになっていた箇所がある。これらはライト配色だと見えなくなるため、すべて `accent` と `onAccent` の組み合わせに置き換えた。

## 主要画面の UI 整理
| 画面 | 主目的 | 主目的と無関係・過剰な要素 | 判断 |
|---|---|---|---|
| ホーム（クラウド一覧と入力欄） | 指示を書いてエージェントを起動し、セッションの状況を見る | 入力欄下の設定チップが常に 5 種類前後並ぶ。特に「ループ · オフ」は既定値なのに常時表示されていた | 目標ループのチップは**必要時だけ表示**（既定値 `off` 以外のとき）。変更自体は「始める場所」「モデル」チップから開く起動設定シートで従来どおり行える。変更した値はチップとして見える状態を保つ |
| ホーム（一覧の絞り込み） | 同上 | 絞り込みタブ | 既存実装がすでに「6 件以上か、絞り込み中のときだけ表示」になっていたため維持した |
| ナビゲーションドロワー | 他のページへ移動する | なし（閉じているときは非表示） | 維持した。配色のみ変更 |
| ページ表示中の承認の帯 | 承認待ちに気づいてチャットへ戻る | 操作を遮らない細い帯 | 維持した。主張を抑えた配色にした |
| ログイン | ログインする | なし | 維持した。主ボタンだけをアクセント色にした |
| アカウントシート | 接続、コスト、ログアウト | なし（取り消し手段として必要） | 維持した |

新しい UI 要素は追加していない。既存要素の配色とスタイルの置き換えだけで対応した。

## 検証結果
- `npm run typecheck` は成功した（変更前も変更後も exit 0）。
- `npx jest --runInBand` は 31 スイート・390 件すべて合格した（変更前も変更後も同じ）。
  - 並列実行ではサンドボックスのメモリ不足で Killed になったため、`--runInBand` で実行した。
- `npx expo export --platform web` は成功した。
- ヘッドレス Chromium（390×844）でログイン画面を描画した。ピクセル集計の結果は次のとおり。
  - 地 `#faf9f5` が大半を占める。
  - 入力欄は白。
  - テラコッタの主ボタン（規約未同意のため半透明）と濃色文字 `#1f1e1b` を確認した。

## 未検証事項（レビュー時に確認してほしい点）
- ログイン後の画面（ホーム、ドロワー、各ページ）は実際の描画で確認できていない。サンドボックスに認証情報がないため。
- iOS/Android 実機の表示も確認できていない。特に次の点を見てほしい。
  - StatusBar の dark 表示
  - セリフ体（Georgia / serif）の見え方
  - 影の強さ
- カンバンの優先度色とラベル色（`src/lib/kanban.ts` と `KanbanScreen.tsx` の直書き色）は機能上の識別色なので変えていない。淡い地での視認性は確認が必要。
- 補助色（success / warning / danger / running）は淡い地で読めるよう濃いめにした。`DiscoverScreen` のテストは色をトークン参照で比較しているため影響はない。
